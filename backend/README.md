# Library Management System (LibMS)

A comprehensive web-based Library Management System for Schools and Colleges.

## Tech Stack
- Frontend: React.js + Vite
- Backend: Node.js + Express.js
- Database: MySQL
- Authentication: JWT

## Features

### Admin
- Dashboard with Charts & Analytics
- Books Management (Add, Search, Delete)
- Members Management (Add, Search)
- Issue & Return Books
- Fine Management
- Reports & Analytics
- Overdue & Low Stock Alerts

### Librarian
- Books Management
- Members View
- Issue & Return Books
- Fine Management

### Student
- Personal Dashboard
- My Issued Books
- My Fines
- Search Books
- Borrowing History
- Book Renewal
- My Profile

## Installation

### Backend Setup
cd backend
npm install
node server.js
### Frontend Setup
cd frontend
npm install
npm run dev
